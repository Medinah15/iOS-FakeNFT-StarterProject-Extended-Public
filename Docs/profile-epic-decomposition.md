Декомпозиция проекта: "Экран профиля и связанные экраны"


Часть 1. Экран профиля (ProfileView) и базовая навигация

Цель: Создать главный экран профиля с навигацией, используя мок-данные для наполнения.


1. Изучение макетов Figma: анализ всех необходимых компонентов, шрифтов, цветов и отступов. - 30 минут 

2. Создание ProfileView с версткой по макету:
- AsyncImage для аватара
- Text для имени и описания
- Button для сайта
- List или LazyVStack для меню - 2 часа 

3. Реализация кастомной ячейки меню ProfileMenuRow с иконкой и текстом. - 1 час 


4. Создание мок-данных для профиля (Profile.mock) и меню. -  30 минут 


5. Настройка навигации в NavigationStack:
- Переход к MyNFTListView
- Переход к FavouriteNFTGridView
- Презентация WebView для сайта - 1.5 часа 

6. Реализация модального окна/экрана редактирования профиля с формой ввода и мок-функционалом сохранения. - 2 часа 

Итого: 7.5 часов 


Часть 2.  Дочерние экраны Мои NFT и "Избранные NFT

Цель: Реализовать экраны NFT с разной компоновкой, используя мок-данные.

1. Создание MyNFTListView с List или LazyVStack для отображения NFT. - 1.5 часа 

2. Верстка кастомной ячейки NFTListRow по макету (иконка, название, автор, цена в ETH). - 2 часа 

3. Создание мок-данных для списка NFT (nft.mockArray) - 30 минут 


4. Реализация кнопки сортировки с Menu или ConfirmationDialog и мок-логикой сортировки списка 1.5 часа 

5. Создание FavouriteNFTGridView с LazyVGrid для отображения избранных NFT. 2 часа 

6. Верстка кастомной ячейки NFTGridCell (иконка, кнопка сердца, название, рейтинг, цена). - 2 часа 

7. Реализация мок-логики удаления из избранного через @State и Binding в ячейке. - 1.5 часа 


Итого 11 часов 



Часть 3 

Цель: Создать сервисы и модели данных, затем подключить их к готовым View.


1. Реализация моделей данных:
- Profile (с соответствием Codable)
- NFT (с рейтингом, ценой в ETH) - 1 час 

2. Создание ProfileService с методами:
- fetchProfile()
- updateProfile( profile: Profile) - 1.5 часа 

3. Создание NFTService с методами:
- fetchUserNFTs()
- fetchFavouriteNFTs()
- removeFromFavourites(nftId: String)  2 часа 

4. Добавление обработки ошибок и кеширования в сервисы (например, с помощью URLCache). - 1.5 часа 

5. Интеграция сервисов в структуру ServicesAssembly или через EnvironmentObject. - 1 час 


6. Замена мок-данных в ProfileView на реальные данные из ProfileService с использованием @State/@StateObject. - 2 часа 

7. Замена мок-данных в MyNFTListView и FavouriteNFTGridView на данные из NFTService с обработкой состояний загрузки/ошибки.  - 2 часа 

8. Связывание функций сортировки и удаления из изрбанного с реальными вызовами сервисов - 1 час 

Итого 12 часов
