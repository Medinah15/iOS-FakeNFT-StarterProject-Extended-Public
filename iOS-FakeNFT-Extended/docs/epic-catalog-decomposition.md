# Эпик: Каталог NFT

**Приложение:** FakeNFT  
**Платформа:** iOS 17+  
**Архитектура:** SwiftUI + MVVM  
**Асинхронность:** Swift Concurrency (async/await, actors)  
**Модели:** Sendable  

---

## Цель эпика

Реализовать функциональность каталога NFT в приложении, включая:
- получение и отображение коллекций NFT из API;
- просмотр содержимого коллекции и деталей каждого NFT;
- фильтрацию, сортировку и навигацию между экранами;
- обработку состояний загрузки, ошибок и пустых данных.

Результатом эпика станет полностью рабочий модуль **«Каталог»**, обеспечивающий пользователю удобный доступ к NFT-контенту.

---

## Часть 1. Логика данных и архитектура

**Задачи:**
1. Прочитать техническое задание и макеты Figma — *30 минут*  
2. Реализовать модели данных `CatalogCollection` и `CatalogItem` — *30 минут*  
3. Реализовать сервис `CatalogService`, который загружает коллекции и NFT из API — *2 часа*  
4. Добавить кеширование и обработку ошибок в `CatalogService` — *1 час*  
5. Интегрировать сервис в `ServicesAssembly`, обеспечив корректную загрузку данных — *30 минут*

**Итого:** 4 часа 30 минут

**Результат:**  
В проекте появляется полноценный слой данных — можно получать коллекции и NFT из сети, обрабатывать ошибки и кэшировать результаты.

---

## Часть 2. Экран каталога

**Задачи:**
1. Реализовать экран каталога с карточками коллекций по макету Figma (включая настройку цветов, шрифтов и отступов) — *2 часа*  
2. Настроить загрузку данных из `CatalogService` и отображение состояний (загрузка, ошибка, пусто) — *1 час 30 минут*  
3. Добавить навигацию: при выборе коллекции открывается экран её содержимого — *1 час*

**Итого:** 4 часа 30 минут

**Результат:**  
Появляется рабочий экран **«Каталог»**, отображающий коллекции NFT и позволяющий перейти к содержимому коллекции.

---

## Часть 3. Экран коллекции и переходы

**Задачи:**
1. Реализовать экран коллекции с гридом NFT по макету Figma — *2 часа*  
2. Добавить сортировку и экран фильтра коллекции — *1 час*  
3. Реализовать переход к детальному экрану NFT (`NftDetailViewController`) — *45 минут*  
4. Реализовать переход в `WebView` по ссылке автора — *30 минут*

**Итого:** 4 часа 15 минут

**Результат:**  
Экран коллекции полностью готов: работает фильтрация, переход к деталям NFT и `WebView`, навигация стабильна.

---

## Общее время

**Итого по эпику:**  
**≈ 13 часов 15 минут**

---

## Ожидаемый результат эпика

После завершения всех частей в приложении появится готовый модуль **«Каталог»**, включающий:
- стабильный слой данных с кэшированием и обработкой ошибок;
- экран каталога с коллекциями NFT;
- экран коллекции с гридом NFT, фильтрацией и переходами;
- возможность просмотра деталей NFT и открытия ссылки автора в `WebView`.

Модуль будет полностью соответствовать макетам Figma и требованиям технического задания.
